# Project photos

Put student work photos here, then list them in `data/projects.js`:

    images: ["assets/projects/bakery-ordering-site-1.jpg", "assets/projects/bakery-ordering-site-2.jpg"],

- The first image is the card cover; the rest show as thumbnails in the pop-up.
- Name files after the project id, e.g. `smart-plant-monitor-1.jpg`.
- Keep them around 1600px wide, JPG or WebP, under ~400 KB each.
- No faces — crop or blur if a student is in the shot.
